실제 운영 때 지킬 것

  1. 이름·연락처는 다른 칸으로 받기홈페이지 문의 양식에서 이름·연락처 칸을 내용 칸과 나눠 받으면, AI에는 내용 칸만 보내면 돼요.
  2. 내용 칸에 섞여 들어온 연락처도 가리기"010-…로 연락 주세요"처럼 본문에 적힌 번호·이메일·주민번호도 보내기 전에 바꿔요. 위 '2번' 칸이 그 과정이에요.
  3. 이름은 병원 명단과 맞춰 가리기글만 보고 이름을 짐작하지 않고, 예약 명단·문의자 이름과 맞는 글자를 [환자1]로 바꿔요.
  4. n8n 실행 기록 저장 끄기성공한 실행의 데이터는 남기지 않게 설정해서, 원문이 자동화 도구 안에 쌓이지 않게 해요.
  5. 학습에 쓰지 않는 요금제 쓰기보낸 글이 AI 학습에 쓰이지 않는 API 요금제를 쓰고, 보관 기간도 확인해요.
  6. 의학적 판단은 하지 않기AI는 증상을 진단하지 않아요. 수술 후 증상 문의를 '긴급'으로 분류해 간호팀에 알리는 데까지만 해요.
  7. 의료광고 규정 지키기전후 사진 요청, 할인·동반 할인 문의에는 '주의'를 붙이고 내원 상담으로 안내해요.
